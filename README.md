# 📚 Study Group Finder

A web-based platform designed to help students discover, create, and join study groups based on shared academic interests, subjects, and learning goals.

The platform promotes collaborative learning by connecting students with like-minded peers, making it easier to study together, share knowledge, and stay motivated.

---

## 🚀 Features

### 👤 User Authentication
- User Registration
- Secure Login & Logout
- Session Management

### 📖 Study Group Management
- Create Study Groups
- Browse Available Groups
- Join Existing Groups
- View Group Details

### 💬 Collaboration
- Connect with students having similar interests
- Encourage peer-to-peer learning
- Facilitate academic discussions

### 🎨 User-Friendly Interface
- Clean and Responsive Design
- Easy Navigation
- Interactive User Experience

## 🎯 Problem Statement

Students often struggle to find peers studying the same subjects or preparing for similar goals. While learning resources are widely available, finding the right study partners remains challenging.

Study Group Finder addresses this problem by providing a platform where students can easily discover and collaborate with others who share their academic interests.
